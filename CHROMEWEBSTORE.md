# Chrome Web Store listing - HelloDev

Last updated: 2026-11-12. **Draft metadata, not a submission or release.**

## Store listing

**Name:** HelloDev

**Short description:** A personal new tab dashboard with shared DevDash bug, PR and CL queries.

**Detailed description:**

Arrange developer work, notes, links, search and a live clock on your new tab.
View shared DevDash bug, pull-request and code-review queries as cards or tables.
Keep the same queries and cached results across your local developer tools.
Choose your own layout, colors and refresh intervals.

Load HelloDev, add widgets, and configure their display settings. Work queries
require separately installed DevDash and its local connection setup.
Provider accounts and query configuration are managed in DevDash.

Dashboard settings can sync through your browser account. Work-query results
are displayed locally and are not included in that settings sync.
See the privacy policy and support links below.

**Category:** Developer Tools

**Single purpose:** A customizable developer new-tab dashboard.

**Primary language:** English

## Permissions justification

| Permission | Reason |
| --- | --- |
| `nativeMessaging` | Read shared developer queries and request refreshes from the separately installed local DevDash host |
| `storage` | Persist and synchronize dashboard settings and remember setup state |
| `topSites` | Offer frequently visited sites in user-configured Links widgets |
| `sessions` | Offer recently closed tabs in user-configured Links widgets |
| `favicon` | Display site icons in Links widgets |

There are **no host permissions** or content scripts. The former identity and
provider-host permissions were removed. The Copilot proposal grants no new
permissions and ships no development host or self-modification feature.

## Privacy and data use

No analytics, ads, sale of data or developer-operated collection endpoint.
The extension processes notes, configured links, selected browser history and
normalized developer-query results to display its dashboard.
Layouts/notes/configuration may be transmitted by browser settings sync.
Search, embedded content and DevDash's selected providers have their own data
flows; see [PRIVACY.md](PRIVACY.md). Do not declare "all data stays on device."

Before any store submission, reconcile the disclosure form against the shipped
package, browser sync and optional widgets; this draft is not a completed form.
Data is not sold, used for unrelated purposes or used for lending decisions.
